# Licencje assetów

Każdy obcy asset (grafika, dźwięk, muzyka, font) musi mieć wpis w tej tabeli, zanim trafi do repo.

Reguły:
1. Dozwolone licencje: wyłącznie CC0 albo CC-BY z atrybucją. Pozostałe odpadają.
2. Asset CC-BY musi być podany w ekranie Credits gry.
3. Źródła CC0 wybieramy z listy w `.claude/skills/asset-gen/`.
4. Assety własne (generowane w `tools/gen_assets.py`) wpisujemy z źródłem „własny".
